# Ugavi - Enterprise SCM for ERPNext

Enterprise Supply Chain Management solution built on ERPNext for NGO-type organizations.

## Features
- Procurement: PR, PO, tenders, sealed-bid opening, supplier prequalification
- Logistics: Stock management, donor-segregated warehousing, monthly reports
- Assets & Fleet: Asset register, vehicle management, fuel tracking
- Governance: Delegation of Authority, segregation of duties, audit trail
- Compliance: Donor rules, budget encumbrance, three-way match

## Quick Start
```bash
make setup && make seed
```

Visit http://ugavi.localhost:8000 | Login: Administrator / admin
